# 5g-Russia-agent-based-model
Код агентно-ориентированной модели российского рынка 5G, построенной в рамках ВКР "Агентное моделирование влияния экономических и регуляторных факторов на развитие 5G в России"

P.S. для успешного запуска модели файлы Subscriber.py, Operator.py и Government.py необходимо объеденить в одну папку с названием agents. Запустите run_experiments для анализа всех сценариев по 30 симуляциям для каждого сценария. 
Запустите demo.py для расмотрения одной симуляции базового сценария.
